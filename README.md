# conorchepenik.com

Personal site for Conor Chepenik — Bitcoin writer, developer, and author of
*The Bitcoin Coloring Book*. Built with Next.js (pages router), React,
Tailwind CSS, and Framer Motion. Deployed on Vercel.

## Local development

```bash
npm install
cp .env.example .env.local   # (optional) set NEXT_PUBLIC_GA_ID
npm run dev
```

The site runs at http://localhost:3000.

## Build

```bash
npm run build
npm start
```
